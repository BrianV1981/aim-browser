# aim-browser Skill

## Description
This skill provides an interactive, LLM-driven headless browser. Use this skill when you need to explore a web page, discover DOM elements, and figure out the exact CSS/XPath selectors needed to interact with the page.

## Available Resources
- \`scripts/run.js\`: The executable wrapper that invokes the \`AimBrowser\` engine.

## Usage
Run the script to launch the browser engine and pass commands.

\`\`\`bash
node scripts/run.js --url "https://example.com"
\`\`\`
